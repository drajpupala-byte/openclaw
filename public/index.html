Claude via MCP — Setup

Connect Claude Code to this app's MCP server to analyze charts for free using your existing Claude subscription.

1
Start the MCP server in a terminal:
npm run mcp
2
Add to Claude Code via /mcp or ~/.claude.json:
{ "mcpServers": { "openclaw": { "command": "npm", "args": ["run", "mcp"], "cwd": "/home/user/openclaw" } } }
3
Ask Claude Code to analyze a symbol:
"Analyze DEMO using the openclaw MCP tools"

Available MCP tools:

• get_chart_summary — compact stats + trend
• get_chart_data — full OHLCV candles
